    Scegli la stampa

    Foglio di stampa proxy

    Carte in scala 1:1 (63 × 88 mm). Per ogni carta puoi cambiare stampa, toglierla dal foglio o mettere una grafica tua con "Grafica". Quando stampi, imposta la scala al 100% e disattiva "adatta alla pagina".

    Grafica personalizzata

    Trascina sull'anteprima per spostare l'immagine, oppure trascina qui un file per caricarlo.

    Tipo di grafica

    Usa le maniglie blu sull'anteprima: alto del box testo, fondo, margini laterali e posizione del nome.

    Regola l'area a mano

    Token del mazzo

    Incolla una lista intera (formato Moxfield, Archidekt o una carta per riga). Cerco su Scryfall i token che ogni carta crea, compresi Tesori, Cibi, Indizi, Eldrazi Spawn e simili.

    Importa un mazzo

    Formati letti: "1 Sol Ring", "1x Sol Ring (CMM) 400", righe con categorie tra parentesi quadre (Archidekt, es. "[Ramp]") o titoli di sezione ("Creature", "// Ramp", "Lands (35)"). Set e numero di collezione, se ci sono, diventano la stampa scelta.
